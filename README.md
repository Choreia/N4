# Choreia N5

JLPT N5 の練習サイト。ひらがな・カタカナ・語彙・漢字・文法・読解を4択で出題し、1問ごとの回答と回答秒数を自社のGoogleスプレッドシートに記録する。

- 公開: https://choreia.github.io/N5/
- 構成: 単一HTML SPA + Google OAuth + Sheets API（サーバー無し）。Choreia モジュール共通のクライアントID・認証方式を踏襲。
- データ: 共有ドライブ内のスプレッドシート（初回セットアップで作成）
  - `問題` … ID／分野／問題／選択肢A〜D／正解(A-D)／解説／有効。行を足せば再デプロイ不要で出題が増える。分野ID = kana / katakana / vocab / kanji / grammar / reading
  - `回答ログ` … 日時／メール／氏名／セッション／問題ID／分野／問題／回答／正誤／回答秒数（1回答=1行、回答直後に追記）
  - `設定` … 予備
- 役割: 学習者（ログインして学習。スプレッドシートへの編集権限が必要）／管理者（全学習者の進捗閲覧、管理者追加）
- 出題: 未出題 > 前回不正解 > 前回正解 の重みで選ぶ。選択肢は画面でシャッフル。
- 初期問題: セットアップ時に76問を `問題` シートへ書き込む（index.html 内 SEED）。

## 学習者を増やすとき
1. 管理画面のリンクからスプレッドシートを開き、学習者のGoogleアカウント（@m2-labo.jp）に「編集者」で共有する
2. 学習者が https://choreia.github.io/N5/ にログインする
